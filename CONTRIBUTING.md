# Contributing

Thank you for your interest in M&M Flow Lab software.

For small corrections, open an issue describing the problem. For code changes, create a focused pull request that explains the motivation, the resulting behavior, and how the change was checked.

Before contributing:

1. Read the repository-specific README and contribution notes.
2. Do not upload confidential research, participant information, credentials, copyrighted material, or unpublished data without authorization.
3. Keep raw experimental data and large videos outside Git. Add a stable link or retrieval instructions instead.
4. Add or update tests when a change affects scientific results or reusable analysis code.
5. Record software dependencies and any random seeds needed to reproduce results.

By contributing, you agree that your work may be distributed under the license stated in the repository.
