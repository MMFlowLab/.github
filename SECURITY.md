# Security policy

Do not open a public issue for a suspected credential leak, exposed private dataset, or security vulnerability.

Contact the repository maintainers privately through the contact method listed in that repository. Include the affected repository, a concise description, and enough information to reproduce the problem without including active credentials or sensitive data.

Revoke exposed credentials immediately through the service that issued them. Removing a secret from the latest commit is insufficient because it may remain in Git history.
